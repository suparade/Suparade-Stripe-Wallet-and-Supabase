Money functionssecurity definer

credit_campaign(campaign, amount, ref)

Credits a budget. The ref is unique, so a repeated Stripe webhook credits once.

reserve_tip(detection, amount, …)

Locks the campaign row, checks the cap, the creator and the balance, then writes the tip and its ledger row in one transaction.

fail_tip(tip, reason)

Stripe said no: marks the tip failed and refunds the budget. Safe to call twice.
