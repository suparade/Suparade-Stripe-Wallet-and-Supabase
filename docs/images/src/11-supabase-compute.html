Why the scout runs on Compute

A full Linux machineffmpeg and streamlink are system binaries. Edge Functions don't give you a full Linux environment.
No time limitA stream runs for hours. A Compute service runs as long as the work takes; serverless functions time out.
Next to the money rulesIt runs in the same Supabase project as the Postgres functions that cap what the agent can spend.
Before Compute: a laptopIt needs ffmpeg and long-running workers, so it could not run serverless.
