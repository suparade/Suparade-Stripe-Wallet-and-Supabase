Built with

Five tools, each with a real job.

Database

Supabase

  • Postgres on Supabase compute is the system of record: 7 tables and an append-only wallet ledger
  • Money rules in SQL: reserve_tip checks budget and cap under a row lock
  • Row level security on every table, Auth for the dashboard, Realtime on paid tips
Agent payments

Stripe

  • The agent pays on its own: a Connect transfer to each creator's account
  • Idempotency key per tip, so a retry never pays twice
  • The agent's reason is written on every transfer
  • Checkout + webhook fund the campaign budget
Multimodal AI

Gemini

  • Flash watches each 10 s clip: video, audio and live chat in one call
  • Returns typed JSON: moments, quotes, sentiment, staging, safety
  • Pro re-checks every candidate and scores the chat's reaction
  • Boxes, text, speech and an image for each alert
Code development

Claude

  • Built with Claude Code: every commit in the repo is co-authored by Claude
  • Supabase schema, payments API, Stripe payouts, detector merge, end-to-end script, docs
  • Claude Opus 5.5, Sonnet 5.5 and Fable 5.1
Hosting

Vercel

  • Hosts the app's payments API as a Python function
  • api/index.py serves the FastAPI app; vercel.json routes every path to it
  • The agent's one call to log and pay a moment: POST /agent/stream-events
How they fit
Gemini sees the moment.
Supabase approves the budget.
Stripe pays the creator.
