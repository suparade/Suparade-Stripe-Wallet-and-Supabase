Built with

Four platforms, one loop from pixels to payout.

Supabase

  • Postgres as system of record, with an append-only wallet ledger
  • security definer SQL functions hold every money rule
  • Row level security and Auth scope brand data to its owner
  • Realtime on tips, so the overlay reacts the moment one is paid

Gemini

  • Flash analyses every clip's video and audio into a JSON schema
  • Pro verifies candidates and scores the chat's reaction
  • Bounding boxes on evidence thumbnails
  • Writes, speaks and illustrates the thank-you alert

Stripe

  • Connect transfers to creators, each with an idempotency key
  • The agent's reason written on every transfer
  • Checkout + webhook to top up campaign budgets

Vercel

  • Hosts the payments API as a Python function
  • The agent's single endpoint for log + pay
